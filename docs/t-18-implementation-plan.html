02

Data flow · what init does

Linear pipeline. Any step can fail loudly — nothing is written until step 5, so an early failure leaves the filesystem untouched.

1
Parse
Typer dispatch · cli/init.py
Resolve --blank / --recipe <name> / --guided; assert at most one. Bare invocation falls through to a friendly error.
2
Validate name
Regex ^[a-zA-Z_][a-zA-Z0-9_-]*$
Keeps the name import-safe for future from <name>.extractors import …. Reject empty, slashes, leading digits.
3
Mode branch
blank → continue · recipe / guided → stub exit
Stubs exit non-zero with their tracking task id. No partial scaffolding happens.
4
Target check
If ./<name> exists and is non-empty
Refuse unless --force. With --force, scaffold files overwrite by name only; foreign files are left alone (no rmtree, ever).
5
Render
Copy cli/templates/blank/ via importlib.resources
Static files. reigner.yaml is written by ReignerConfig.write_default(target, name) — single source of truth, no duplication.
6
Report
Rich tree + 3-line next-steps
One render call to rich.console.Console.print(Tree(...)), then the cd/cp/help block.

reigner/cli/init.py · mode dispatch
import re
from pathlib import Path
import typer
from rich.console import Console
from rich.tree import Tree
from reigner.config import ReignerConfig

NAME_RE = re.compile(r"^[a-zA-Z_][a-zA-Z0-9_-]*$")
console = Console()

def register(app: typer.Typer) -> None:
    # Bound at registration time so test runners get a fresh Typer per run.
    app.command("init")(_init)

def _init(
    name: str = typer.Argument(..., help="Project name (also the target directory)."),
    blank: bool = typer.Option(False, "--blank", help="Empty stubs only."),
    recipe: str | None = typer.Option(None, "--recipe", help="Copy a recipe scaffold."),
    guided: bool = typer.Option(False, "--guided", help="Interactive Q&A."),
    force: bool = typer.Option(False, "--force", help="Overwrite scaffold files."),
) -> None:
    modes = [m for m, v in (("blank", blank), ("recipe", recipe), ("guided", guided)) if v]
    if len(modes) > 1:
        typer.echo("✗ pass at most one of --blank / --recipe / --guided", err=True); raise typer.Exit(2)
    if not modes:
        _print_mode_help(); raise typer.Exit(2)
    if not NAME_RE.match(name):
        typer.echo(f"✗ invalid project name {name!r}; must match [a-zA-Z_][a-zA-Z0-9_-]*", err=True)
        raise typer.Exit(2)

    if recipe:
        typer.echo(f"✗ Recipes are not yet bundled (tracked in T-32). Use --blank for now.", err=True)
        raise typer.Exit(1)
    if guided:
        typer.echo("✗ Guided init is not yet wired. Use --blank for now.", err=True)
        raise typer.Exit(1)

    _scaffold_blank(Path(name), force=force)
    _print_success(Path(name))
reigner/cli/init.py · scaffolding
from importlib.resources import files

def _scaffold_blank(target: Path, *, force: bool) -> None:
    if target.exists() and any(target.iterdir()) and not force:
        typer.echo(f"✗ ./{target} already exists and is non-empty. Pass --force to overwrite.", err=True)
        raise typer.Exit(1)

    target.mkdir(parents=True, exist_ok=True)
    template_root = files("reigner.cli.templates") / "blank"
    for entry in _walk(template_root):
        rel = entry.relative_to(template_root)
        dest = target / rel
        dest.parent.mkdir(parents=True, exist_ok=True)
        dest.write_bytes(entry.read_bytes())

    # single source of truth — never duplicated as a template file.
    ReignerConfig.write_default(target / "reigner.yaml", name=target.name)
05

Risks

All ranked by what hurts the user the most. The HIGH risks must be addressed in this PR.

RiskSeverityMitigation
--force destroys user work High Never rmtree. Overwrite only file paths the scaffold itself owns; foreign files (e.g. the user's edits in library/raw/) are untouched. Test: pre-create a stray file, run with --force, assert it still exists.
Templates missing from built wheel High Add tool.hatch.build.targets.wheel.force-include entry (or rely on package-data globs) and add a CI smoke test that runs uv build && pip install dist/*.whl && reigner init … --blank in a clean venv.
reigner.yaml drifts from ReignerConfig schema Med Always emit via ReignerConfig.write_default. Add a test that round-trips the scaffold yaml through ReignerConfig.load with zero extra="forbid" errors. Catches it the moment the schema gains a required field.
Stub message rots when T-32 lands Med Centralise stub text in one constant per mode. T-32's PR diff will surface the constant; reviewer flips it then.
Name regex permits names that shadow stdlib (os, sys) Low Out of scope for blank mode (we don't generate imports of the project name). Revisit when --guided ships and the project name actually becomes a package.
Windows path separators in golden tests Low Compare set-of-paths, not strings. Path.relative_to + normalise to POSIX in assertions.
Rich tree output unstable across versions Low Don't snapshot stdout. Behavior tests check exit code + file presence; only the file contents are golden-snapshotted.

Still-open question

The interview resolved scope, modes, structure, naming, UX, and tests. One small thing is worth flagging before implementation.

Q · --force semantics on user-edited scaffold files
If a user has hand-edited REIGNER.md and re-runs init demo --blank --force, do we silently overwrite or warn?
Rec: silent overwrite, but print the list of overwritten paths in the success report. The whole point of --force is "I know what I'm doing"; warnings on every file would be noise. We can add a --dry-run flag later if the noise complaint comes up.
