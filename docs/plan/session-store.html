05

Key code

The three places it's easiest to get this wrong: the append loop (must be crash-safe), the load path (must handle missing or stale meta), and the auto-save hook on run_stream.

reigner/sessions/store.py — append_event
def append_event(self, session_id: str, event: Event) -> None:
    self._validate_id(session_id)               # reject path separators & ".."
    line = events.to_json(event)                # raises on non-JSON-coercible fields
    path = self._jsonl_path(session_id)
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("a", encoding="utf-8") as f:
        f.write(line + "\n")
        f.flush()                               # durable per event
    self._dirty_meta.add(session_id)            # meta written lazily
reigner/sessions/store.py — read_meta (rebuilds if missing)
def read_meta(self, session_id: str) -> SessionMeta:
    self._validate_id(session_id)
    meta_path = self._meta_path(session_id)
    if meta_path.exists():
        data = json.loads(meta_path.read_text("utf-8"))
        if data.get("schema_version") != events.SCHEMA_VERSION:
            raise events.SchemaVersionMismatch(...)
        return SessionMeta(**data)
    # sidecar missing — reconstruct from jsonl scan
    return self._rebuild_meta(session_id)
reigner/harness/agent.py — auto-save hook on run_stream
async def run_stream(self, query: str) -> AsyncIterator[Event]:
    self._state.append_turn(Turn(role="user", content=query))
    s = self.harness.settings
    async for event in run_loop(
        self._state, session_id=self.id, cache=self._cache,
        default_char_limit=s.max_tool_result_chars,
        char_limits=s.tool_result_char_limits,
        seq_start=len(self._events),
    ):
        self._events.append(event)
        if self._store and self._auto_save:
            self._store.append_event(self.id, event)   # durable per event
        yield event
    if self._store and self._auto_save:
        self._store.write_meta(self.id, self._build_meta())
06

Future scope

What this task deliberately leaves on the table, plus assumptions worth challenging during review.

Replay & fork-tree navigation

Reconstructing an AgentState (history · notes · citations · cache) from a stored event stream is genuinely a different shape of work — it has to walk the events, re-derive Turns, and decide what's deterministic. Session.load returns an inspection-only Session today; T-25 will replace the NotImplementedError with a real replay.

Decide with · T-25 owner · next sprint

Token & cost accounting in meta

SessionMeta intentionally omits total_tokens and total_cost: no event carries them yet. When a later task (likely the cost-tracking work referenced in SPEC §13) emits a UsageEvent or attaches usage to FinalAnswerEvent, the meta builder grows two fields and the schema bumps from 1 to 2. Stored sessions stay readable via SchemaVersionMismatch + a tiny migration helper.

Decide with · cost-tracking task · TBD

Multi-process / concurrent writers

Assumed single-writer-per-session for v0 — no fcntl.flock, no .lock sidecar. Two processes opening the same session_id would interleave appends. Acceptable for a debugging library; if a downstream user (eval runner running cases in parallel) trips on it, an advisory lock can land without changing the public API.

Decide with · eval runner author (T-28) · only if it bites

Title auto-derivation

title is nullable; set_title is the only writer. We considered auto-deriving from the first user query but rejected it — it couples store logic to query semantics and surprises users running batch scripts. The CLI (reigner session list) can render <untitled> until set, and we revisit if users keep asking.

Decide with · CLI task (T-21) reviewer

Export bundle vs single file — assumption flagged

SPEC §11.2 shows Session.export(... path="./session.jsonl") — a single file. We honor that signature but write a sidecar path.meta.json next to it so title and created survive the round trip. If the reviewer would prefer a one-file format with an embedded meta header line, the wire format extension is small.
